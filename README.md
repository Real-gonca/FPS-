# FPS-

Otimizações de desempenho para jogos no PC.

## BlueStacks 5 + Free Fire (90 FPS / ping baixo)

Guia completo, arquivos prontos e scripts de aplicação/rollback:

➡️ **[bluestacks/README.md](bluestacks/README.md)**

Resumo do pacote:

| Arquivo | Para quê |
|---|---|
| `bluestacks/bluestacks.conf` | Configuração otimizada do emulador (drop-in) |
| `bluestacks/nvidia/BlueStacks-FreeFire-90FPS.nip` | Perfil pronto para o NVIDIA Profile Inspector |
| `bluestacks/scripts/Aplicar-Otimizacoes.ps1` | Aplica com backup automático |
| `bluestacks/scripts/Restaurar-Backup.ps1` | Reverte tudo |

---

As otimizações num PC melhoram o desempenho e a eficiência: ajudam o computador a
funcionar mais rápido, de forma mais suave, e a usar os recursos (memória e processador)
de maneira mais inteligente.
