# FPS-

As otimizações num PC melhoram o seu desempenho e eficiência. Basicamente, elas ajudam o computador a funcionar mais rápido, de forma mais suave e a usar os seus recursos (como memória e processador) de maneira mais inteligente.

## Conteúdo

- **[PROMPT_OTIMIZACAO_PC.md](PROMPT_OTIMIZACAO_PC.md)** — prompt completo (com anexos técnicos) para gerar um kit de otimização de Windows para jogos e emuladores: `Optimize.ps1`, `Optimize.cmd`, `Reverter.cmd` e `README.md`.
  - Perfis progressivos: **Safe → Balanced → Extreme**, com `-DryRun`, backup em JSON e reversão total em um comando.
  - Foco em ganho real: VT-x/Hyper-V, VBS/HVCI, Game DVR, plano de energia, exclusões no antivírus e configuração interna do emulador.
  - Inclui **base técnica** (tabela de impacto, serviços, chaves de registro, lista de "nunca desativar") e um **prompt de auditoria** para revisar o script gerado.
